# pair-wise-yy-58 大型构件吊装三维校核平台

围绕大型转换桁架吊装方案，提供三维场景、时间轴校核、冲突定位、条件评论和多角色签署工作流。页面支持拖动旋转吊装场景、编辑步骤参数、处理规则冲突、恢复本地草稿并锁定发布版本。

## 技术栈

Vue 3、Quasar、Pinia、Vue Router、Apollo Client、GraphQL、Three.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

端口：`62058`

```bash
npm run build   # 含 vue-tsc 类型检查
npm run check   # 复核批次核心流程的端到端断言（59 项）
```

## 带基线的复核批次

三维步骤、冲突复核结论、条件评论、四方会签统一纳入「复核批次」，解决多标签页/多角色轮流复核时后保存覆盖前人数据、失效会签继续放行的问题。

- **先取批次号再修改**：`取得批次号` 时冻结全量对象的基线版本（`src/review/server.ts` 中的 `captureBaseline`）。批次内所有改动先暂存，提交前不影响服务端版本。
- **整批乐观并发**：提交时逐个对象比对基线版本号，任一对象已被他人改过即**整批退回冲突清单**，不产生部分写入（`commitBatch`）。
- **三种冲突处理**：退回清单按字段展示本方/对方差异，可选
  - 保留本方（mine）、保留对方（theirs）；
  - 保留双方（both）：数值取安全保守侧（荷载率/风速取大、净空取小）、步骤结论取更严格、文本双稿署名拼接；
  - 按字段合并（fields）：每个差异字段单独选择保留侧（`src/review/merge.ts`）。
- **会签级联失效**：每个角色持有按管辖范围（步骤参数字段 + 开放评论 + 冲突结论）计算的签署指纹。参数或评论更新后，相关角色会签**立即失效**（无关角色不受影响）；发布锁同时自动解除，需重新会签。门禁在锁定前重新校验全部指纹，失效会签无法放行（`src/review/rules.ts`）。
- **断网恢复**：批次（基线、暂存改动、退回冲突及处理意见）持久化在浏览器 `localStorage`；断网提交转为离线暂存，关闭页面后重新打开自动恢复未完成批次，网络恢复后可原批次重提。顶栏可切换在线/离线模拟，跨标签页通过 `storage` 事件同步权威状态。
- **旧稿升级**：检测到无版本号的旧稿（`yy58-lift-plan-draft`）时自动迁移：全部对象标记为 V1、按当前参数补建冲突复核记录、保留原 revision 与数据；旧稿原件逐字备份到 `yy58-lift-plan-draft-migrated-backup`，页面顶部展示迁移通知。

权威方案状态存于浏览器 `localStorage`（键 `yy58-server-state-v2`），Apollo 内存缓存保存发布锁定时的方案版本快照；界面偏好（当前角色、选中步骤、视角书签）存于 `yy58-ui-prefs-v2`。
